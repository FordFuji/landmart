สรุป เรียน Opencart
1. เอา Template จาก Design มา โฟลเดอร์ css, js, images เอาใส่ใน catalog/view/theme/default/media/
2. หน้า Design เอาใส่ใน catalog/view/theme/default/template/common Backup comment ไว้ก่อนก็ดี
3. แยกไฟล์เป็น Header, Footer
4. หน้าในมี {{ header }} กับ {{ footer }}
5. Controller สำหรับเชื่อมต่อกับ View
6. Model สำหรับ Query ฐานข้อมูล
7. View เป็นไฟล์ twig ประกาศค่าตัวแปร PHP หรือมี ภาษา PHP ไม่ได้

** ล้าง Cache system\storage\cache ลบไฟล์ข้างในโฟลเดอร์ cache ให้หมด
** Twig ประกาศค่าตัวแปร PHP ไม่ได้ ได้แต่ HTML
